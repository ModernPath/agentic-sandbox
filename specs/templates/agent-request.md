# Agent request

Copy this form into a new GitHub issue (or use the **Agent request** template). Answer in plain language. "Don't know" is a valid answer; the builder will ask you about it.

## 1. What should the agent do?
- In one or two sentences, what job does it do for the team?
- What do you do by hand today that it would replace or speed up?
- Give one realistic example of a request and the result you expect.

## 2. Who uses it?
- Who will ask for results (role, not name)?
- How often will it run, roughly?

## 3. What information does it need?
- Which information comes from the web, from uploaded files, or from the team's own records?
- Does it need to read any records the sandbox already holds (accounts, signals, briefs)? Which?

## 4. What does it keep?
- What should be stored after a run? For how long?
- Does it contain personal data (names, roles, contact details, notes about people)? If yes, who can see it, and when must it be deleted?

## 5. What leaves the sandbox?
- Does it send anything outside the sandbox (to a web service, a model provider, Slack, email)? List each one.
- Is anything sent to a person? If yes, it must be a draft that someone approves first.

## 6. What does a run cost?
- Which paid services does it use (web search, a language model, others)?
- What is the most you are willing to spend per run?

## 7. What must never happen?
- For example: "it must never invent a source", "it must never show another team's accounts".

## 8. What does done look like?
- Describe the output a reviewer should see when the agent works.
- Give one example of an output that would be wrong.

## 9. Open questions for the builder
- Anything you are unsure about.
